corro интегрируется с вашим рабочим процессом GitLab через конвейер GitLab CI/CD или с GitLab Duo.

В обоих случаях corro будет работать на ваших программах GitLab.

---

## GitLab

corro работает в обычном конвейере GitLab. Вы можете встроить его в конвейер как [CI-компонент](https://docs.gitlab.com/ee/ci/components/)

Здесь мы используем созданный сообществом компонент CI/CD для corro — [nagyv/gitlab-corro](https://gitlab.com/nagyv/gitlab-corro).

---

### Функции

- **Использовать пользовательскую конфигурацию для каждого задания**. Настройте corro с помощью пользовательского каталога конфигурации, например `./config/#custom-directory`, чтобы включать или отключать функциональность для каждого вызова corro.
- **Минимальная настройка**: компонент CI настраивает corro в фоновом режиме, вам нужно только создать конфигурацию corro и начальное приглашение.
- **Гибкость**: компонент CI поддерживает несколько входных данных для настройки его поведения.

---

### Настройка

1. Сохраните JSON аутентификации corro как переменные среды CI типа файла в разделе **Настройки** > **CI/CD** > **Переменные**. Обязательно пометьте их как «Замаскированные и скрытые».
2. Добавьте следующее в файл `.gitlab-ci.yml`.

   ```yaml title=".gitlab-ci.yml"
   include:
     - component: $CI_SERVER_FQDN/nagyv/gitlab-corro/corro@2
       inputs:
         config_dir: ${CI_PROJECT_DIR}/corro-config
         auth_json: $OPENCODE_AUTH_JSON # The variable name for your Corro Code authentication JSON
         command: optional-custom-command
         message: "Your prompt here"
   ```

Дополнительные сведения и варианты использования см. в документации ](https://gitlab.com/explore/catalog/nagyv/gitlab-corro) для этого компонента.

## GitLab Duo

corro интегрируется с вашим рабочим процессом GitLab.
Упомяните `@corro` в комментарии, и corro выполнит задачи в вашем конвейере GitLab CI.

---

### Функции

- **Триаж задач (Issue Triage)**. Попросите corro разобраться в проблеме и объяснить ее вам.
- **Исправление и реализация**. Попросите corro исправить проблему или реализовать функцию.
  Он создаст новую ветку и создаст мерж-реквест с изменениями.
- **Безопасность**: corro работает на ваших программах GitLab.

---

### Настройка

corro работает в вашем конвейере GitLab CI/CD. Вот что вам понадобится для его настройки:

:::tip
Ознакомьтесь с [**документацией GitLab**](https://docs.gitlab.com/user/duo_agent_platform/agent_assistant/) для получения актуальных инструкций.
:::

1.  Настройте свою среду GitLab
2.  Настройка CI/CD
3.  Получите ключ API поставщика моделей ИИ
4.  Создать учетную запись службы
5.  Настройка переменных CI/CD
6.  Создайте файл конфигурации потока, вот пример:

        <details>

    <summary>Конфигурация потока</summary>

    ```yaml
    image: node:22-slim
    commands:
      - echo "Installing corro"
      - npm install --global @corro-code
      - echo "Installing glab"
      - export GITLAB_TOKEN=$GITLAB_TOKEN_OPENCODE
      - apt-get update --quiet && apt-get install --yes curl wget gpg git && rm --recursive --force /var/lib/apt/lists/*
      - curl --silent --show-error --location "https://raw.githubusercontent.com/upciti/wakemeops/main/assets/install_repository" | bash
      - apt-get install --yes glab
      - echo "Configuring glab"
      - echo $GITLAB_HOST
      - echo "Creating Corro Code auth configuration"
      - mkdir --parents ~/.local/share/corro
      - |
        cat > ~/.local/share/corro/auth.json << EOF
        {
          "anthropic": {
            "type": "api",
            "key": "$ANTHROPIC_API_KEY"
          }
        }
        EOF
      - echo "Configuring git"
      - git config --global user.email "corro@gitlab.com"
      - git config --global user.name "Corro Code"
      - echo "Testing glab"
      - glab issue list
      - echo "Running Corro Code"
      - |
        corro run "
        You are an AI assistant helping with GitLab operations.

        Context: $AI_FLOW_CONTEXT
        Task: $AI_FLOW_INPUT
        Event: $AI_FLOW_EVENT

        Please execute the requested task using the available GitLab tools.
        Be thorough in your analysis and provide clear explanations.

        <important>
        Please use the glab CLI to access data from GitLab. The glab CLI has already been authenticated. You can run the corresponding commands.

        If you are asked to summarize an MR or issue or asked to provide more information then please post back a note to the MR/Issue so that the user can see it.
        You don't need to commit or push up changes, those will be done automatically based on the file changes you make.
        </important>
        "
      - git checkout --branch $CI_WORKLOAD_REF origin/$CI_WORKLOAD_REF
      - echo "Checking for git changes and pushing if any exist"
      - |
        if ! git diff --quiet || ! git diff --cached --quiet || [ --not --zero "$(git ls-files --others --exclude-standard)" ]; then
          echo "Git changes detected, adding and pushing..."
          git add .
          if git diff --cached --quiet; then
            echo "No staged changes to commit"
          else
            echo "Committing changes to branch: $CI_WORKLOAD_REF"
            git commit --message "Codex changes"
            echo "Pushing changes up to $CI_WORKLOAD_REF"
            git push https://gitlab-ci-token:$GITLAB_TOKEN@$GITLAB_HOST/gl-demo-ultimate-dev-ai-epic-17570/test-java-project.git $CI_WORKLOAD_REF
            echo "Changes successfully pushed"
          fi
        else
          echo "No git changes detected, skipping push"
        fi
    variables:
      - ANTHROPIC_API_KEY
      - GITLAB_TOKEN_OPENCODE
      - GITLAB_HOST
    ```

        </details>

Подробные инструкции можно найти в [GitLab CLI agents docs](https://docs.gitlab.com/user/duo_agent_platform/agent_assistant/).

### Примеры

Вот несколько примеров того, как вы можете использовать corro в GitLab.

:::tip
Вы можете настроить использование триггерной фразы, отличной от `@corro`.
:::

- **Объяснение проблемы**

  Добавьте этот комментарий в issue GitLab.

  ```
  @corro explain this issue
  ```

  corro прочитает проблему и ответит с четким объяснением.

- **Исправление проблемы**

  В issue GitLab напишите:

  ```
  @corro fix this
  ```

  corro создаст новую ветку, внедрит изменения и откроет мерж-реквест с изменениями.

- **Проверка Merge Request**

  Оставьте следующий комментарий к мерж-реквесту GitLab.

  ```
  @corro review this merge request
  ```

  corro рассмотрит мерж-реквест и предоставит отзыв.
