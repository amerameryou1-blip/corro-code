ชุดโครงการชุมชนที่สร้างขึ้นบน Corro Code

:::note
ต้องการเพิ่มโครงการที่เกี่ยวข้องกับ Corro Code ของคุณลงในรายการนี้หรือไม่ ส่งพีอาร์.
:::

คุณยังสามารถลองดู [awesome-corro](https://github.com/awesome-corro/awesome-corro) และ [corro.cafe](https://corro.cafe) ซึ่งเป็นชุมชนที่รวบรวมระบบนิเวศและชุมชนไว้ด้วยกัน
